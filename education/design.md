# Education Page Design Notes

## Current Purpose

The education page presents formal training and certifications across human factors, biomedical engineering, cloud/full-stack development, biomechanics, and embodied systems.

This page is meant to explain the foundation behind the portfolio rather than repeat the experience page. It should show how Shrey's education maps into clinical AI, product design, medical-device thinking, research methods, and coaching/biomechanics.

## Current Visual Approach

The page uses large bordered education bands:
- Degrees are emphasized as large horizontal sections.
- Each degree has coursework/theme details on the left and explanatory context/links on the right.
- Certifications are presented as two side-by-side cards below the degree section.
- Expandable `details` are still used on this page for coursework groupings because the page can otherwise become too long.

Current category color language:
- Red: tech stack / education-coded items
- Blue: concepts, themes, frameworks, experience tags
- Purple: live links and internal reference links

## Design Intent So Far

The current page is built to show that the portfolio is not a random set of projects. It explains the training stack behind the work:
- Human factors provides research, evaluation, trust, interface, and behavior-change methods.
- Biomedical engineering provides clinical, biomechanical, anatomical, device, and systems constraints.
- Certifications and bootcamp/cloud training provide applied implementation and coaching range.
